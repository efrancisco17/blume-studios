The Phases

Phase 1: Inquiry Responder & Follow-ups

Paste raw inquiry → Claude extracts details → checks calendar → drafts personalized reply (under 170 words) → queues for approval → saves lead

Also: Auto-flag stale leads (no contact 3+ days), batch draft follow-ups

Phase 2: Prospecting Agent

Search venues/planners/coordinators by location & radius → Google Places API finds them → scores for fit → drafts partnership pitches → queues for approval

Live progress: "Researching venue 7 of 25…"

Phase 3: Approval Queue & Outreach Tracking

Every draft (replies, follow-ups, pitches) queued for review → edit if needed → approve to create Gmail draft → tracks sequences (3-touch max, 7-day spacing) → detects replies

Compliance: Do-Not-Contact list, never email twice in 7 days

Phase 4: Scheduled Daily Routine & ROI

Runs daily (configurable time): check for replies → process due follow-ups → draft stale lead follow-ups → generate morning summary

Reports: Revenue & conversion rate by source, cost per booking, recommendations to keep/cut sources

Phase 5: Content Generation

Generate SEO venue landing pages using only real weddings shot there → generate Google Business Profile posts from booked weddings

Hard Rules (Built Into Code)

  • Nothing ever sends without approval (all emails are Gmail drafts only)
  • No scraping (only public APIs and websites)
  • Only contact businesses (venues, planners, never couples)
  • 7-day rule enforced (never email same person twice in 7 days)
  • 3-touch max (stop sequences after 3 no-replies)
  • Do-Not-Contact list maintained
  • Full compliance footer on every outreach (name, address, opt-out)
  • Action log tracks every email and decision
  • Never invent facts (no made-up prices, awards, wedding details)

Getting Started (5 minutes)

@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) & { background: #1c1917; color: #e0ddd9; } }
# 1. Install
cd backend && npm install
cd ../frontend && npm install

# 2. Configure (.env)
cp .env.example .env
# Add ANTHROPIC_API_KEY, GOOGLE_* keys, GMAIL_ADDRESS

# 3. Run
Terminal 1: cd backend && npm start
Terminal 2: cd frontend && npm run dev

App opens at http://localhost:5173
