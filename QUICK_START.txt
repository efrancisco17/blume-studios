BLUME STUDIOS WEDDING BOOKING AGENT
Quick Start (5 minutes)

1. INSTALL
   cd backend && npm install
   cd ../frontend && npm install

2. CONFIGURE (.env)
   cp .env.example .env
   Edit .env and add:
   - ANTHROPIC_API_KEY (from console.anthropic.com)
   - GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET (from Google Cloud)
   - GOOGLE_PLACES_API_KEY (from Google Cloud)
   - GMAIL_ADDRESS (your Gmail)

3. RUN
   Terminal 1: cd backend && npm start
   Terminal 2: cd frontend && npm run dev
   App opens at http://localhost:5173

4. CONNECT GMAIL
   Settings → Integrations → Connect Gmail
   (First time only)

5. TEST
   Go to Inquiry tab
   Paste: "Hi! I'm Alex, marrying on June 14 at The Estate. Found you on Instagram. 8 hours?"
   Click "Process Inquiry"
   See extracted data and draft reply
   Go to Queue, click Approve
   Draft appears in Gmail

COMMON ISSUES
"ANTHROPIC_API_KEY not set" → Add to .env, restart backend
"Google OAuth credentials not configured" → Add credentials to .env, restart
"Calendar checks show unknown" → Settings → Connect Gmail
"Gmail drafts not creating" → Same as above
"Places search fails" → Check GOOGLE_PLACES_API_KEY in .env

FILE STRUCTURE
